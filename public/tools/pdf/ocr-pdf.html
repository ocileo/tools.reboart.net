FAQ - Pertanyaan yang Sering Diajukan
Apa itu OCR?
OCR (Optical Character Recognition) adalah teknologi yang mengubah gambar teks menjadi teks digital yang dapat diedit dan dicari.
Format file apa yang didukung?
Support PDF, JPG, JPEG, dan PNG. Untuk PDF, direkomendasikan PDF scan atau PDF dengan gambar.
Apakah data saya aman?
100% aman! Proses OCR dilakukan menggunakan Tesseract.js di browser Anda. File tidak pernah dikirim ke server.
Berapa akurasi OCR?
Akurasi tergantung kualitas gambar/scan. Dokumen dengan resolusi tinggi dan teks jelas akan memberikan hasil lebih akurat.
Berapa batas ukuran file?
Maksimal 20MB per file. Untuk file lebih besar, disarankan di-split terlebih dahulu.
Apakah ada watermark?
Tidak ada watermark sama sekali. Hasil OCR bersih dan profesional.
