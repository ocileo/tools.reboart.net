FAQ - Pertanyaan yang Sering Diajukan
Apa yang terjadi jika saya lupa password?
Sayangnya, jika Anda lupa password, tidak ada cara untuk membuka PDF yang diproteksi. Simpan password dengan aman.
Apakah proteksi ini aman?
Ya! Menggunakan enkripsi AES-256 yang merupakan standar keamanan tertinggi untuk PDF.
Apakah data saya aman?
100% aman! Semua proses dilakukan di browser Anda. File tidak pernah dikirim ke server.
Bisakah proteksi dihapus?
Ya, dengan menggunakan alat "Unlock PDF" atau software PDF lain yang mendukung penghapusan password.
Berapa batas ukuran file?
Maksimal 50MB per file. Untuk file lebih besar, disarankan di-split terlebih dahulu.
Apakah ada watermark?
Tidak ada watermark sama sekali. Hasil proteksi bersih dan profesional.
