FAQ - Pertanyaan yang Sering Diajukan
Apa yang dilakukan PDF Rotator?
PDF Rotator memutar halaman PDF ke sudut yang diinginkan (90°, 180°, atau 270°) untuk memperbaiki orientasi yang salah.
Bisakah rotasi per halaman?
Ya! Gunakan mode "Satu Halaman" atau "Range Halaman" untuk memilih halaman tertentu yang ingin dirotasi.
Apakah kualitas PDF berubah?
Tidak, kualitas PDF tetap sama. Rotasi hanya mengubah orientasi halaman, bukan konten.
Apakah data saya aman?
100% aman! Semua proses dilakukan di browser Anda. File tidak pernah dikirim ke server.
Berapa batas ukuran file?
Maksimal 50MB per file. Untuk file lebih besar, disarankan di-split terlebih dahulu.
Apakah ada watermark?
Tidak ada watermark sama sekali. Hasil rotasi bersih dan profesional.
